## 需要保持一致的资料

商家 / 商品编号 / 相册组号映射；商品形态 / 主体与部件材料 / 来源；尺寸值与单位 / 来源 / 颜色；肉度、玉化度、光泽感、完整度、瑕疵度、工整度、顺色度；基础确认 / 细分待补 / 规则版本；两路用途批准 / 包摘要 / 接收回执 / 有效性。

## 保留业务规则与具体定位

### WAREHOUSE-01 四仓职责

商城不算四仓；销售与风格直接接分类资料，分别签收，不互相代传。

验收：一边拒绝时另一边可独立接收；各自能查到同一版本的收据。

对应定位：W-C01、W-C03、W-A02。实现状态：原入口存在；是否完整满足规则需按缺项收口。

收口记录：WAREHOUSE-G01、WAREHOUSE-G02、WAREHOUSE-G03、WAREHOUSE-G04、WAREHOUSE-G05。

### WAREHOUSE-02 分类人工确认

主图有效、形态明确、主体材料有人工值及来源，才可确认基础分类；价格和七维未齐可待补。

验收：无主图时拒绝确认；基础确认后仍能看到细分待补。

对应定位：W-C02。实现状态：原入口存在；是否完整满足规则需按缺项收口。

收口记录：WAREHOUSE-G01、WAREHOUSE-G02、WAREHOUSE-G03、WAREHOUSE-G04、WAREHOUSE-G05。

### WAREHOUSE-03 七项观察与单珠

无标准可写观察，不能造档位；无绳不能直接判高肉度；单珠位置与材料分别确认。

验收：无档表时选择框禁用；观察可存；手串单珠标记缩放不跑偏。

对应定位：W-C02。实现状态：原入口存在；是否完整满足规则需按缺项收口。

收口记录：WAREHOUSE-G01、WAREHOUSE-G02、WAREHOUSE-G03、WAREHOUSE-G04、WAREHOUSE-G05。

### WAREHOUSE-04 价格与筛选

价格需负责人独立确认来源、计价单位与有效期；区间跨档就显示跨档。

验收：单颗价不混整串价；空值不当低档；不同筛选维度同时满足。

对应定位：W-A01。实现状态：原入口存在；是否完整满足规则需按缺项收口。

收口记录：WAREHOUSE-G01、WAREHOUSE-G02、WAREHOUSE-G03、WAREHOUSE-G04、WAREHOUSE-G05。

### WAREHOUSE-05 独立收据

同号同包重试只接收一次；同号不同内容拒绝；请求成功不等于对方保存。

验收：超时先查原号；错误商家、错误摘要或过期版本不能签收。

对应定位：W-A02。实现状态：原入口存在；是否完整满足规则需按缺项收口。

收口记录：WAREHOUSE-G01、WAREHOUSE-G02、WAREHOUSE-G03、WAREHOUSE-G04、WAREHOUSE-G05。

### WAREHOUSE-06 风格资格与生图分开

资格通过只说明资料可交；真实生图另需提供方、预算、许可与产物验收。

验收：没有实际生成文件时始终不显示生图成功。

对应定位：W-C03。实现状态：原入口存在；是否完整满足规则需按缺项收口。

收口记录：WAREHOUSE-G01、WAREHOUSE-G02、WAREHOUSE-G03、WAREHOUSE-G04、WAREHOUSE-G05。

### WAREHOUSE-07 更新与撤回

修改形成新版本，旧资料停止新用途；分别记录两路撤回处理结果。

验收：销售撤回完成而风格未响应时，总览仍显示部分待处理。

对应定位：W-A02。实现状态：原入口存在；是否完整满足规则需按缺项收口。

收口记录：WAREHOUSE-G01、WAREHOUSE-G02、WAREHOUSE-G03、WAREHOUSE-G04、WAREHOUSE-G05。

## 缺项、差异与待验证

### WAREHOUSE-G01 销售链当前只是内部预览

类别：范围限制。原页明确preview_only；不能把预览收件包装成已正式销售放行。

收口标准：指定双方合同与版本，真实接收方有有效回执，正式用途另行批准。

证据：[W01](../source-ui/warehouse/local_upload_page.html) 第356行

责任：业务负责人和对应模块开发共同确认。未虚构人员、排期、准确率或上线状态。

### WAREHOUSE-G02 两路回执与撤回未现场复验

类别：待验证。页面和需求已有交接，当前未使用真实下游重做签收、乱序、重启和撤回验证。

收口标准：同号重试只收一次，旧版不覆盖新版；两路撤回各有回执。

证据：[W02](../source-ui/warehouse/PRD-V1.5.md) 第252行

责任：业务负责人和对应模块开发共同确认。未虚构人员、排期、准确率或上线状态。

### WAREHOUSE-G03 七项观察与标准设置的页面覆盖

类别：待核对。V1.5要求七维与规则发布；当前本地审核台不等于完整标准配置界面，不能根据部分字段判断全缺或全有。

收口标准：在指定分支逐项定位七维、单珠、档表、规则发布与影响预览；未落实项再拆任务。

证据：[W02](../source-ui/warehouse/PRD-V1.5.md) 第121行

责任：业务负责人和对应模块开发共同确认。未虚构人员、排期、准确率或上线状态。

### WAREHOUSE-G04 图片上限两个入口定义不同

类别：待对齐。相册是20,000,000字节，分类文档为20 MiB；需明确入口与接收映射。

收口标准：两个入口使用准确字节数和各自提示，边界样本验证。

证据：[A01](../source-ui/album/Android-Demo-PRD-V1.3.md) 第27行

责任：业务负责人和对应模块开发共同确认。未虚构人员、排期、准确率或上线状态。

### WAREHOUSE-G05 正式图片交接入口在两个本机目录中不同

类别：候选版本差异。所选8124运行目录的原页面只在路线说明中提到正式图片交接字段，未定位formal-handoff-panel。开发主目录候选则有该面板，不能把两个目录拼成当前运行版本。

收口标准：由团队选定正式前后端候选，将交接面板、权限与真实回执在同一版本验证；保留原页面，不新建一套替代。

证据：[W05](../source-ui/warehouse/local_upload_page_candidate.html) 第418行

另一候选对照：[W01](../source-ui/warehouse/local_upload_page.html) 第311行

责任：业务负责人和分类/相册开发共同确认。未虚构人员、排期、准确率或上线状态。

### WAREHOUSE-G06 相册收件箱及免费风格演示的数据库依赖未恢复

类别：实际运行阻断。实测8124收件箱HTTP 500，日志为数据库ConnectionRefusedError；18119免费三张图返回local_demo_database_unavailable。未将空列表当成交接成功。

收口标准：在当前候选恢复正确数据库与对象存储，原页重同步有有效收件回执，免费示例图生成成功。

证据：[W01](../source-ui/warehouse/local_upload_page.html) 第367行

责任：对应原项目维护人；未虚构具体人员或排期。未虚构人员、排期、准确率或上线状态。
