## 需要保持一致的资料

任务号 / 图片号 / 内容摘要；原图与裁图关联 / 商品组 / 展示主图；接收数 / 已上传数 / 已处理数 / 问题数；算法版本 / 人工修订 / 导出版本；用途授权 / 下游收据。

## 保留业务规则与具体定位

### ALBUM-01 接收与边界

只面向指定 Android；JPEG、PNG、HEIC；单任务目标 10,000 张；大于 20,000,000 字节拒收。

验收：等于 20,000,000 可收，多 1 字节拒收；同名不同内容不当重复。

对应定位：A-C01。实现状态：需求或服务级，不能判作已有界面。

收口记录：ALBUM-G01、ALBUM-G02、ALBUM-G03。

### ALBUM-02 断点恢复

断网、锁屏和重开后核对实际已接收照片，只补未完成部分。

验收：上传中断后数量守恒，重开不要求重新选整批。

对应定位：A-C01。实现状态：需求或服务级，不能判作已有界面。

收口记录：ALBUM-G01、ALBUM-G02、ALBUM-G03。

### ALBUM-03 分组不鉴定

同任务同实物分组，相似但无法判断时先分开；不输出真伪、价格和产地。

验收：单图、多角度、合照、模糊图和相似实物各有处理去向。

对应定位：A-C01、A-A01。实现状态：需求或服务级，不能判作已有界面。

收口记录：ALBUM-G01、ALBUM-G02、ALBUM-G03。

### ALBUM-04 改错与撤销

支持合并、拆分、裁切、换主图、标无关与撤销；原相册不删除。

验收：两组 3+2 张合并为 5，撤销恢复且不漏图。

对应定位：A-C01、A-A01。实现状态：需求或服务级，不能判作已有界面。

收口记录：ALBUM-G01、ALBUM-G02、ALBUM-G03。

### ALBUM-05 完成口径

结束添加且有效图均有结果、无待确认无未处理失败才算整理完成。

验收：有失败结束显示已结束有未处理照片；待分类不妨碍相册完成。

对应定位：A-C01。实现状态：需求或服务级，不能判作已有界面。

收口记录：ALBUM-G01、ALBUM-G02、ALBUM-G03。

### ALBUM-06 真实资料包

导出包含 products.xlsx、manifest.json 和实际 images；冻结点击时版本。

验收：解压可读且图数对应；重试不混入后来修改或其他商家图片。

对应定位：A-A01。实现状态：需求或服务级，不能判作已有界面。

收口记录：ALBUM-G01、ALBUM-G02、ALBUM-G03。

### ALBUM-07 下游确认

未分类可交，但有未决分组不能交；分类与正式编号由分类仓返回。

验收：无收据仅显示待发送；不能自造正式编号。

对应定位：A-A02。实现状态：需求或服务级，不能判作已有界面。

收口记录：ALBUM-G01、ALBUM-G02、ALBUM-G03。
