# 1. 产品结论

本产品面向珠宝门店和内容团队，用“我店” Pixel 原生窗口接收素材、发起剪辑和查看进度，由 Mac 本地服务完成素材管理、AI 分析、剪辑、版本与审核，内容负责人可在电脑工作台做更细的审片和管理。

产品的价值不是“AI 自动发布”，而是把找素材、出初稿、改稿和交接变成一条可追溯的流程。它像一个会帮忙备菜的剪辑助理，不是可以代替店主做最终决定的自动驾驶系统。

## 1.1 一句话目标

让普通店员在手机上上传或接收素材，说清想做什么，获得可播放的剪辑初稿，完成审核、修改、剪映精修交接和人工分发，全程不需要看终端或文件路径。

| 不承诺 | V1.2 不对外宣称 | 生产可用、自动发布、自动判断珠宝价格/材质/产地/真伪、所有手机按钮均已上线 |

# 3. 业务目标与成功指标

## 3.1 业务目标

1. 降低找素材成本：用日期、类型、来源、客户和自定义标签快速定位。
2. 缩短初稿时间：素材和需求确认后，系统生成可播放、可追溯的候选。
3. 降低改稿沟通成本：每次修改生成新版本，保留原稿、意见和父子关系。
4. 保护客户素材：未授权、已撤权、跨客户和失效版本必须失败关闭。
5. 让手机与电脑看到同一份事实：不能出现手机已上传、电脑素材库看不到，或两端进度不一致。

## 3.2 V1.2 签收指标

- 2 名非开发人员可独立完成“上传→初稿→改稿→导出”，不看终端。
- 一组已授权真实素材和一条参考片在同一固定代码版本上跑完主流程。
- 字幕重点术语正确，字幕与声音的时间误差达到约定门槛；未达标片段自动进入人工审核，不冒充通过。
- 任意成片可追溯到需求、素材、参考规则、字幕、生成参数和操作人。
- 撤权、版本冲突、中断恢复、网络中断和备份恢复完成定向验收。

## 3.3 反指标

- 不以“测试数量多”代替真实效果。
- 不以“页面打开”代替视频可播放、任务可恢复和两端已同步。
- 不以“打开剪映”代替工程或文件已成功交接。
- 不以“规格符合”代替平台已允许发布。

# 4. 用户与操作路径

## 4.1 角色

| 角色 | 主要操作 | 不应获得的权限 |
|---|---|---|
| 店主/店员 | 手机上传素材、说明想法、看进度、审初稿、提修改 | 不看系统路径、模型日志、密钥或跨客户素材 |
| 内容负责人 | 电脑上管理素材、参考片、规则、版本、批量审核和导出 | 不绕过权限、事实和发布闸门 |
| 系统服务 | 分析、匹配、剪辑、版本、证据和恢复 | 不自动发布，不自动把候选识别当商品事实 |

## 4.2 主流程

1. 手机、电脑或授权硬件把视频/图片/音频放入收件箱。
2. 用户播放确认，再加日期、来源、类型和标签；确认后进入素材库。
3. 用户用一句话说明想做的内容，可加必须保留和禁止出现的要求。
4. 系统从已授权素材中推荐可用片段，并说明为什么选、缺什么。
5. 用户可上传参考样片，系统候选拆解节奏、转场、画面、字幕和音频；用户确认采用哪些规则。
6. 用户确认素材与规则映射，再生成初稿。
7. 用户播放初稿，批准、拒绝或提修改；修改生成新版，不覆盖原版。
8. 满意时导出本地交付包；需要精修时生成剪映交接包，由人工导入和回传。
9. 系统检查平台规格并给出候选文件；最终发布由人确认并操作。

## 4.3 关键操作故事

> 以下人名是为了让流程容易阅读的匿名代称，不是真实客户资料。

### UJ-01 阿琳在手机上发起剪辑

阿琳是门店店员。她在“我店”上传一条中文名视频，先播放确认是正确文件，再选“产品展示”并加“南红”标签。她输入“做一条讲清设计灵感的小红书视频”。系统先给可播放素材和选择理由，她确认后才发起生成。任务在 Mac 处理时，她在手机上看到明确进度，完成后直接播放初稿。

### UJ-02 陈姐在电脑上审核和改稿

陈姐是内容负责人。她在电脑工作台按内容类型和平台筛选待审核作品，播放视频并查看来源素材、字幕门和风格执行差异。她提出“保留开头，中段节奏更快，不改原声”。AI 先给修改方案，她确认后才生成 V2。V1 仍可追溯，V2 明确显示修改内容和父版。

### UJ-03 阿琳将作品交给剪映精修

阿琳对 V2 基本满意，但需要在剪映里微调花字。她选小红书为目标平台，填写精修说明，生成本地交接包。系统只记录“已生成交接包”和“已打开应用/文件夹”，不冒充已导入。她人工导入、精修和导出后，将文件回传到原作品再审核。

### UJ-04 阿琳在断网或失败后恢复

阿琳发起任务后手机与 Mac 短暂断开。手机不得显示假完成，而是显示最后已确认状态和连接异常。恢复后，系统通过任务 ID 和回执继续原任务；若返回了多个候选，必须让她选择，不得猜一个继续。

# 5. 功能需求

## 5.1 会话、权限与恢复

- **FR-001** 每次创作绑定客户、会话、操作人和版本；跨范围请求必须拒绝。
- **FR-002** 手机与电脑显示同一个任务 ID、状态和最后更新时间。
- **FR-003** 中断后恢复精确任务；存在多个候选时必须让人选，不得猜测。
- **FR-004** 首次安全绑定后保存设备授权；授权失效、设备变更或人工撤销时重新绑定。

## 5.2 素材接收与素材库

- **FR-010** 接收 MP4、MOV、JPG、PNG 和经验收的音频格式，拒绝空文件、伪装格式和超限文件。
- **FR-011** 原文件只读；计算摘要去重，任何剪辑只操作副本。
- **FR-012** 上传成功后立即显示中文文件名、可播放预览、接收日期、拍摄日期、来源、类型、标签和可读位置。
- **FR-013** 上传结果、重新查询、页面刷新和另一端同步必须指向同一素材 ID。
- **FR-014** 素材支持日期、类型、来源、客户和多个自定义标签，并支持搜索、筛选、排序和分页。
- **FR-015** 素材卡片可直接播放，不得只显示文件名或黑框。
- **FR-016** 支持单选、本页全选和批量操作；选中、处理中、成功和失败文案必须清楚可见。
- **FR-017** 删除先进垃圾箱，默认保留 30 天；保留期内可恢复，仅内容管理员可永久删除，且必须二次确认并保留审计记录。
- **FR-018** 素材撤权后阻断新的分析、匹配、渲染、采用和导出，已生成记录保留但标记失效。

## 5.3 需求与素材匹配

- **FR-020** 采集主题、受众、目标、必须保留和禁止出现的内容；空素材库时保留用户已输入的想法并引导上传。
- **FR-021** 输出“可做、部分可做、不可做”三种结论，每个推荐片段显示来源和理由。
- **FR-022** 素材不足时先查找已授权历史素材，再让用户缩小范围、接受明示替代或暂停；不虚构镜头，不自动派发补拍。
- **FR-023** 推荐原视频必须可播放，用户确认素材和任务书精确版本后才可生成。

## 5.4 参考样片与风格规则

- **FR-030** 用户可上传参考样片或选历史成片，并声明自有、获授权或仅学风格。
- **FR-031** “仅学风格”默认禁止复用参考片的原音频、原片段和可识别内容。
- **FR-032** 系统将参考片拆为节奏、叙事、镜头、转场、字幕和音频等候选规则，每条显示证据和置信状态。
- **FR-033** 用户选择并确认要模仿的规则；未确认的模型结论不得直接驱动剪辑。
- **FR-034** 系统把规则映射到已授权素材，显示替代项和无法实现的差异，经人确认后才渲染。
- **FR-035** 执行报告逐条说明“完成、近似、未执行”，不得只给综合分数。
- **FR-036** 参考规则、权利或素材版本变化时，已生成候选精确失效。

## 5.5 生成、平台版本和字幕

- **FR-040** 生成母版、小红书、抖音、视频号四种独立候选；平台版在开头、节奏、时长、结构、字幕或包装上存在业务差异。
- **FR-041** 每版显示平台用途、实测宽高、时长、比例、格式和规格检查结果；规格通过不等于平台审核通过。
- **FR-042** 渲染记录素材区间、规则版本、字幕版本、参数和文件摘要。
- **FR-043** 修改生成新版本，保留原版、父版、意见和生成证据。
- **FR-044** 字幕前先结合画面、原声、上下文和珠宝术语库形成候选；低置信、专有名词和数值进入人工审核。
- **FR-045** 字幕时间轴与音频绑定；修改文字不得默默改变原始音频或素材摘要。
- **FR-046** 字幕质量门必须检查开头句、珠宝术语、单位、时间对齐、重叠、空窗和越界；异常时阻断自动采用。

## 5.6 审片、修改与批量操作

- **FR-050** 作品页显示可播放视频、来源素材、版本、平台、内容类型和主要质量提示。
- **FR-051** 反馈分为问题、期望、必须保留和禁止项，保留原始文字和结构化结果。
- **FR-052** AI 先提交修改方案，人确认后才生成新版；确认前不得后台自动出 V2。
- **FR-053** 最终采用绑定一个精确版本；旧版、失效版和未审核版不能进入待发布。
- **FR-054** 素材、审片、待发布都支持删除到垃圾箱；已对外导出的文件明确提示不能自动召回。
- **FR-055** 列表支持本页全选、批量通过、批量驳回、批量移入垃圾箱和批量准备发布；操作前显示选中数量和作用范围。

## 5.7 创作入口、移动端与硬件

- **FR-060** 创作入口显示可用素材数量，提供“看视频”和“上传视频”；无素材时不创建空任务。
- **FR-061** 上传后立即显示完整素材卡片，且刷新、重登录和另一端同步后仍存在。
- **FR-062** 上传后提供“用这些素材开始”；已有需求时显示“继续匹配素材”。
- **FR-063** 客户可创建多个自定义标签；内容类型与发布平台分开管理。
- **FR-064** 作品页提供“修改这版→用剪映精修”，先收集修改要求和目标平台，再生成交接包。
- **FR-065** “我店” Pixel 原生窗口作为手机主入口，提供上传、发起剪辑、进度、预览、审核和修改；不用网页假冒原生交付。
- **FR-066** 手机与电脑对素材、任务、版本、标签、垃圾箱和进度使用同一身份与回执；提交时必须校验用户开始编辑时的版本。若另一端已更新，本次提交失败并显示冲突，后提交者必须刷新后重新确认，系统不得静默覆盖。
- **FR-067** 硬件路径为“设备素材→手机网关→Mac 收件箱→人工预览确认→素材库”；断线、重复上传和错误时不丢原文件。
- **FR-068** 手机明确显示排队、分析、剪辑、待审核、修改、失败和已完成；失败时给出可重试动作和原因。

## 5.8 剪映交接与平台分发

- **FR-070** 剪映交接包至少包含目标成片、可选源素材、修改说明、目标平台、摘要和版本关系。
- **FR-071** 打开剪映、打开文件夹、人工导入、导出和回传分别记录结果；未通过的步骤不得串成“已同步”。
- **FR-072** 回传版本绑定原作品和父版，重新进入审片；不覆盖 AI 原稿。
- **FR-073** 分发窗口显示母版、小红书、抖音和视频号候选，包含规格、标题/文案候选、权利提示和人工确认。
- **FR-074** V1.2 默认为人工导出和发布；直连平台 API 必须单独完成账号、权限、回执、失败恢复和平台合规验收后才能开启。

# 6. 非功能要求

## 6.1 安全与隐私

- 原素材、凭据、本地路径、原始模型输出和供应商内部信息不向手机或普通浏览器回显。
- 所有写操作幂等，重试不能重复创建作品、任务或发布请求。
- 设备长期授权保存在系统安全存储，APK 不内置长期密钥。
- 垃圾箱默认保留 30 天；只有内容管理员可永久删除。备份和云端保留需明确加密、访问权限和恢复测试。

## 6.2 可用性

- 手机页面单页单主任务，底部或顶部保留明确返回和下一步，不用无限长列表承载全部信息。
- 视频多时使用缩略图网格、类型/日期分组、搜索、筛选、分页和批量操作，而不是把全部文字展开。
- 重要按钮、状态和错误使用大字、高对比和可读文案，并在系统放大字体后仍可操作。
- 电脑端采用单页单主功能，技术证据收进详情，不与客户主操作混排。

## 6.3 可靠性与性能

- 上传、分析、渲染、同步和导出都支持中断恢复，失败后不留半文件。
- 任务状态、回执、版本关系和素材摘要必须持久化，服务重启后可恢复。
- 长列表必须分页或虚拟渲染，不得因素材或作品数量增长导致手机无法操作。
- 性能指标须在指定机器和真实素材上校准，不把局部超时或合成样本速度当成业务承诺。

# 7. 产品边界

## 7.1 V1.2 包含

- 我店 Pixel 原生入口与 Mac 本地后台。
- 手机、电脑与授权硬件的素材收件箱。
- 素材库、搜索、分类、标签、垃圾箱和版本。
- 参考样片风格规则候选与人工确认。
- 初稿、审片、AI 修改方案、新版本和批量操作。
- 字幕/声音对齐质量门和珠宝术语人工审核。
- 剪映本地交接包、导出回传复审和人工分发。

## 7.2 V1.2 不包含

- 未经单独验收的剪映工程自动写入或任意剪映 API 直连。
- 无人值守的小红书、抖音、视频号或微信自动发布。
- 自动判断珠宝材质、价格、产地或真伪并当作业务事实。
- 公网 SaaS、多租户计费和客户数据跨机迁移。
- “上传一条参考片就可以保证完全复制风格”的效果承诺。

# 8. 验收计划

## Gate 0：基线冻结

- 固定同一 Git SHA、APK 摘要、模型/提示词版本、素材摘要和运行环境。
- 清单列出已实现、合成验证、真实素材候选、外部未验证。
- code34 在通过手机、声音、AI 理解和业务闭环前不得替代 code31 验收基线。

## Gate 1：素材闭环

- 合成视频完成上传、播放、中文名、日期、来源、标签、搜索、分类、删除和恢复。
- 手机与电脑查询到同一素材 ID；其他客户/会话不能读取。
- 删除的素材进入 30 天垃圾箱；普通店员无法永久删除，内容管理员恢复与永久删除都有回执。

## Gate 2：创作与修改闭环

- 从手机输入想法，匹配可播放素材，确认后生成初稿。
- 审核人提不满意意见，AI 生成修改方案，人确认后出 V2，V1 保留。
- 任务可在服务重启、App 重启和短暂断网后恢复。
- 在手机与电脑同时编辑同一标签或审核状态的用例中，先提交的新版本保留，后提交的请求收到冲突并要求刷新，数据不被静默覆盖。

## Gate 3：真实参考样片与字幕

- 使用已授权真实珠宝素材和参考片，人工确认风格规则和素材映射。
- 节奏、叙事、转场、画面、字幕、音频逐维评分，不用单一综合分替代。
- 术语、数值、开头句和时间对齐完成人工审核；修正候选不自动进入训练。

## Gate 4：剪映与分发边界

- 以小红书为目标生成交接包，分别验证打开应用、打开文件夹、人工导入、导出和回传。
- 回传版本回到原作品审核链，未经人确认不进入待发布。
- 发布请求和外部网络动作默认为 0。

## Gate 5：可用性和规模

- 在电脑、Pixel 标准字体、Pixel 大字体和窄宽显示下完成真实页面验收。
- 至少用大量合成记录验证搜索、筛选、分页、全选、批量审核、批量删除和批量准备发布。
- 2 名非开发人员独立完成指定任务，记录卡点、误触和完成时间。

# 9. 阶段顺序

1. **P0 基线和 PRD 冻结**：固定 V1.2、代码、APK、证据口径和状态词典。
2. **P1 素材及两端同步**：上传、播放、标签、搜索、垃圾箱、手机/电脑一致。
3. **P2 初稿和修改**：发起任务、进度、初稿、AI 修改方案、人工确认、V2。
4. **P3 真实风格与字幕门**：参考样片、珠宝术语、声画对齐、人工评分。
5. **P4 剪映交接和回传**：先把文件交接做稳，再单独判断是否存在可验收的直连能力。
6. **P5 四平台候选与人工分发**：业务差异、规格、权利、回执和失败恢复。

# 10. 术语表

| 术语 | 统一含义 |
|---|---|
| 收件箱 | 手机、电脑或硬件传来、尚未经人工预览确认的文件区 |
| 素材 | 经确认、有身份、摘要、权限和版本的视频、图片或音频 |
| 参考样片 | 用于提取候选剪辑风格规则的视频，不等于可复用其原内容 |
| 作品 | 由一次需求和一组已授权素材形成的可审核内容对象 |
| 候选 | 系统已产生但尚未被人最终采用的作品版本 |
| 版本 | 不可覆盖、可追溯父子关系的一次精确输出 |
| 采用 | 人工选定一个精确版本进入导出或待发布 |
| 交接包 | 用于剪映或外部人工精修的本地文件集，不等于已导入剪映 |
| 回执 | 说明某一步是否完成、对应哪个对象与版本的可验证记录 |
| 可受控试用 | 只允许指定人、指定设备和指定素材使用，仍不代表生产发布 |

# 11. 已决策与待后续校准项

## 11.1 已决策

- **DEC-01 垃圾箱**：默认保留 30 天；仅内容管理员可永久删除；恢复与永久删除都需回执和审计。
- **DEC-02 两端冲突**：采用版本校验；先提交的新版本保留，后提交者必须刷新并重新确认，禁止静默覆盖。

3. 第一个要做深度适配的平台是小红书、抖音还是视频号？

## 11.3 假设索引

当前没有未标注的产品假设。后续校准项已明确列在 § 11.2。

# 12. 完成定义

V1.2 只有在同一固定代码和 APK 基线上，同时通过素材、手机/电脑同步、初稿、修改、真实风格、字幕声音、剪映交接、恢复、权限和非开发人员可用性验收，才能标记为“可受控试用”。

任何一项缺失，均必须标记为“候选”或“未验证”，不得使用“完成”、“全部打通”、“真实业务通过”或“可生产”等表述。
